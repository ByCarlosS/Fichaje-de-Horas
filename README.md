# Mis Horas Extra

Web para fichar la entrada y la salida y calcular las horas extra.

- Jornada configurable por día de la semana, con descanso y otras tareas incluidas.
- Conceptos: jornada normal, descanso no cogido, hora extra, día libre trabajado, festivo trabajado y otros.
- Resumen mensual e informe en PDF y CSV.
- Inicio de sesión con Google y sincronización entre dispositivos (Firebase); cada usuario ve solo sus datos.
